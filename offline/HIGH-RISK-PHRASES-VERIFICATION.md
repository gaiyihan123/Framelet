# 离线翻译修正复核 · 1.1.1

原 Argos 离线模型仍用于普通句子。针对 1.1.0 抽查暴露的问题，为 7 类可明确识别的完整句型加了本机结构规则；模型输出中的已识别货币文字会恢复为原来的货币符号和数字。规则没命中的内容仍使用模型。模型权重与模型运行环境未更换。

| 英文句型 | 1.1.0 样本结果 | 1.1.1 结果 |
|---|---|---|
| meeting moved from Monday to Friday at 3 PM | 被译成会议从周一一直到周五举行 | 会议原定星期一，现改至星期五下午3点 |
| report by Friday | “星期五前”可能会被读为周五之前，不含当天 | 最迟应于星期五提交报告 |
| changes before 5 PM today reviewed tomorrow | 两个时间混在同一段，截止关系不清 | 今天下午5点前作出的更改，将于明天审核 |
| reduce total by 15%, not to 15% | 两种百分比含义混在一起 | 将总额减少15%，而不是减少到15% |
| refund after returned item received | 把“收到退货”译成“收到退款” | 收到退回的商品30天后才会退款 |
| trial lasts two weeks after installation | “试用期”译成法律上的“审判” | 软件安装后的试用期为2周 |
| only delete files newer than 30 days | “最近30天内”的范围不明 | 只删除最近30天内的文件 |
| source contains $120 and $150 | 模型自行写作 120元、150元 | 保留 `$120`、`$150` 原符号 |

## 回归情况

- 相同 26 条样本经完整 1.1.1 翻译客户端重跑，结构规则覆盖 7 条，货币符号保护覆盖 2 条，实际运行零次网络调用。
- 其余 17 条继续走 Argos 离线模型；其中包括先后、否定、日期、文件筛选、快捷键和 UI 指令。模型结果仍须人工核对。
- 93 项全套构建检查通过；实际安装后再通过 93 项应用检查、13 项 worker 检查。实际安装 UI 另以合成英文画面实测 OCR、离线翻译和中英对照图。
- 完整逐条前后译文见同目录 `model-quality-audit-1.1.1.json`。样本是刻意挑出的高风险句式，不是随机测试集，也不代表整体准确率。规则要求整句匹配；OCR 改动、额外附加条件、别的语序或没列入的用法仍回到模型翻译。

译文是便于阅读的本机草稿。法律、医疗、财务、日期、操作指令等重要内容仍应对照原文。
